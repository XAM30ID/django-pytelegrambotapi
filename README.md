Это самописный шаблон для создания проекта в связке **Django** + **pyTelegramBotAPI**.

## Установка:
### 1. клонировать репозиторий:
`git clone https://github.com/XAM30ID/django-pytelegrambotapi.git`

### 2. Создать виртуальное окружение и активировать его:
`python -m venv .venv`
`.venv/scripts/activate`

### 3. Создать .env (переменные окружения):
В файле надо прописать следующие переменные:
BOT_TOKEN=Токен бота
HOOK=Вебхук для бота
OWNER_ID=ID админа бота

### 4. Базовая структура готова.

В каталоге bot находится вся логика работы с ботом (инициализация, view для бота, обработчики и т. д.)
Так же в проект без проблем можно добавить новое приложение, например для веб-части при помощи инструментов Django:
`python manage.py startapp my_app`
